夹爪合上，并不意味着已经抓住。接触力出现，也不意味着物体就会跟着上升。这个实验把“碰到”“夹紧”和“带起”拆成三个可以观察的阶段。

[打开实验 07 · 夹持与接触力](/lab/?example=arm-contact#experiment)。方块具有独立的自由关节，实验没有把它绑定到夹爪上；它是否能被抬起，由实际接触、摩擦与运动共同决定。入口动画仅演示操作顺序，判断结果请看实验中的实时读数。

## 从相同的起点出发

进入本实验会重置机械臂和方块，并恢复默认摩擦系数 0.8。先保持正常速度，按顺序操作，每一步稳定后再继续：

1. **对准方块**：机械臂移动到预设夹持姿态，夹爪两侧靠近方块。
2. **闭合夹爪**：观察左右夹指的法向接触力是否建立。闭合度表示执行器目标，不代表夹指已经穿过物体达到这个距离。
3. **抬起观察**：检查方块中心高度是否明显上升，并继续保持；不要只看夹爪自己在上升。
4. **松开夹爪**：观察接触力下降、方块重新受到重力影响而下落。

暂停后可用单步观察，但单次物理步长只有 2 ms，肉眼不一定能立即看出位置变化。

## 法向力负责压紧，摩擦抵抗滑动

两个夹指沿相反方向的滑动轴闭合，因此可以用相同的正目标位移控制它们。模型里的 `touch` 传感器覆盖夹指接触区域，记录区域内的法向接触力合计，并不是直接报告向上的摩擦力。其含义见[触觉传感器说明](https://mujoco.readthedocs.io/en/stable/XMLreference.html#sensor-touch)。

对于对称、准静态的理想侧向夹持，可以用下面的关系建立直觉：

```text
可提供的向上摩擦 ≲ μ · (N_left + N_right)
需要支撑的重量 = m · g
```

这不是网页求解器使用的替代公式。实际结果还会受到接触位置、姿态、加速度和求解过程影响。这里的方块质量为 0.07 kg，重量约 0.69 N；即使法向力相同，减小摩擦也会减少抵抗滑落的能力。

## 做一组反例，比只看成功更有用

先用默认参数完成一次抬升，再重置，把摩擦系数降到 0，重复相同的对准、闭合、抬起步骤。

在低摩擦的侧向夹持中，你可能仍能读到明显的夹指法向力，却看到方块留在台面或从夹爪中滑落。两种结果并不矛盾：压紧与支撑向上的重量是不同作用。

本站的摩擦滑块统一修改模型中几何体的滑动摩擦系数，因此也会影响方块与台面的相互作用。比较时保持姿态和操作顺序一致，把方块高度、左右力和画面放在一起判断。

## 接触点数量也不是成功标志

界面显示的总接触数包含方块与工作台等接触。方块安静地放在台面上时，这个数也可能大于零。

抓取是否成功，至少应同时看：夹指建立接触、方块离开原高度，以及方块在抬升后是否持续被支撑。实验中的 touch 传感器读数已经足够观察这一步，无需把接触点数量当成布尔开关。

下面的 Python 片段在加载本站模型后使用：

```python
# 两个夹指关节轴向相反，正目标位移都表示向内闭合。
for name in ("left_servo", "right_servo"):
    actuator = mujoco.mj_name2id(
        model, mujoco.mjtObj.mjOBJ_ACTUATOR, name
    )
    data.ctrl[actuator] = 0.065

mujoco.mj_step(model, data)
mujoco.mj_forward(model, data)

sample = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_BODY, "sample")
print("方块中心高度:", data.xpos[sample, 2])
```

下载[完整运行包](/examples/arm-lab.zip)，执行 `python arm.py --example contact`，程序会自动完成一轮对准、闭合、抬起与松开。用 `--friction 0` 再运行一次，比较结果。

从实验 03 的滑块到这里的夹持，摩擦始终在抵抗相对滑动；变化的是接触方向与承担的任务。把前面的模型层级、关节控制和状态读取放到一起，才能解释这一次抬起为什么发生。
