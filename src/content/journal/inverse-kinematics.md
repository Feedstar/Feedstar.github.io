在[多关节控制](/journal/arm-control/)中，我们逐个告诉关节应该转到哪里。现在，把一枚金色的目标放进空间，问题变成：这些关节应该如何配合，才能让末端靠近它？

[打开实验 08 · 末端追踪与逆运动学](/lab/?example=inverse-kinematics#experiment)。拖动金色目标可改变水平位置，Z 滑块改变高度。青色点迹记录实际末端走过的位置，金色目标表示我们希望抵达的地方。

## 先分清三种位置

实验同时保留三个层次：空间中的目标、逆运动学计算出的关节构型，以及真正受到执行器驱动的机械臂。

“实际位置误差”比较目标与真实末端。“逆解残余误差”比较目标与求解构型的末端。“关节跟踪误差”则是实际关节角与求解角之间的最大偏差。

逆解已经找到一个合适姿态时，机械臂仍需要时间运动。反过来，如果目标本身不可达，执行器已经抵达求解角，末端也依然不会到达目标。

## 用局部变化，寻找关节方向

正运动学把关节角变成末端位置。雅可比矩阵描述当前构型附近的一小段对应关系：

```text
Δx ≈ J(q) · Δq
```

本实验使用 MuJoCo 的 [mj_jacSite](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-jacsite) 取得末端 site 的平移雅可比，只选取四个机械臂关节对应的速度列。夹指和方块的自由度不参与位置求解。

这是局部近似，所以求解需要反复更新位置、计算误差，再作小步修正。

## 阻尼让求解避开过大的步长

在接近伸直等构型时，有些末端运动方向很难由小幅关节运动产生。直接求逆容易得到过大的关节变化。这里使用阻尼最小二乘：

```python
# J: 3 × 4 平移雅可比；error: 目标位置 − 当前求解位置
A = J @ J.T + damping**2 * np.eye(3)
delta = J.T @ np.linalg.solve(A, error)
q_next = np.clip(q + np.clip(delta, -0.12, 0.12), lower, upper)
```

每次控制更新最多进行 12 次迭代，单次关节增量限为 0.12 rad，并检查关节范围。求解阻尼 λ 调节的是这个数值过程，它与执行器 PD 中的速度反馈 Kd 是两回事。

较大的 λ 通常让单次修正更保守，但它不能让关节突破限位，也不能让短机械臂够到任意远处。

## 求解状态与物理状态分开

网页和 Python 程序都使用独立的 `MjData` 进行运动学求解。求解结束后，只把四个关节目标写入实际仿真的执行器控制量：

```python
# scratch 用于寻找构型，data 用于真实动力学仿真。
solved = scratch.qpos[joint_qpos_addresses].copy()
data.ctrl[:4] = solved
mujoco.mj_step(model, data)
```

实际机械臂使用 Kp = 180、Kd = 20 的位置执行器，保留 ±90 N·m 的力矩上限和机械臂重力补偿。控制目标每 10 ms 更新，物理仿真每 2 ms 前进一步。位置变化来自执行器和动力学，而不是把物理关节直接设到求解角。

当前四轴机械臂只追踪三维位置，夹爪方向会随构型变化。本实验没有附加任意空间姿态约束，也没有规划避障路径。

## 做三次对照

1. 选择“定点对照”，等实际位置误差稳定，再对比逆解误差与关节跟踪误差。
2. 选择“圆形轨迹”。目标在 YZ 平面画一个半径 0.10 m 的圆，观察实际轨迹与高度曲线。提高轨迹角速度，比较运动中的滞后。
3. 选择“不可达目标”。观察残余误差和关节读数。显示“未收敛 / 可能不可达”是一种求解结果提示，不是对所有构型进行过全局可达性证明。

参数变化会清空旧曲线，便于看清新条件。预设会从相同初始姿态重来；暂停后可以按 2 ms 单步查看物理响应。
