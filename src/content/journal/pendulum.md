一枚摆从偏离平衡的位置松开。它穿过最低点，向另一侧升起，再回到原处附近。几行模型描述，便能让这个熟悉的过程在屏幕里发生。

本站的第一个示例，从这里开始：不急着建立复杂的机器人，先看清一个自由度怎样运动。

## 先把世界描述清楚

MuJoCo 的 MJCF 模型用 XML 描述物体、关节、几何形状和物理参数。在这个示例中，世界里有地面和固定支点；支点下的刚体通过一个铰链关节旋转。

```xml
<body name="pendulum" pos="0 0 1.7">
  <joint name="hinge" type="hinge" axis="0 1 0" damping="0.12"/>
  <geom type="capsule" fromto="0 0 0 0 0 -1" size="0.018" mass="0.1"/>
  <geom type="sphere" pos="0 0 -1" size="0.095" mass="1"/>
</body>
```

`body` 建立局部坐标系。连杆和摆球的位置都相对于这个坐标系描述。`joint` 指定它相对父物体可以怎样运动，这里只允许绕局部 Y 轴旋转。

这个模型的连杆也有质量，摆球也有尺寸。因此，它是一个便于观察的物理摆，与“无质量连杆加质点”的理想单摆存在细微区别。

## 模型与状态，分别存放什么

可以把 `MjModel` 看作世界的结构与参数，把 `MjData` 看作这一刻的状态与计算结果。

- 模型记录关节结构、质量、阻尼等信息。
- 状态记录关节位置、速度、仿真时间等信息。
- 调用 `mj_step` 后，仿真向前推进一个时间步。

对于这里的单个铰链关节，`qpos[0]` 是角度，单位为弧度；`qvel[0]` 是角速度。示例从约 0.85 rad 的初始角度释放。

## 阻尼让运动慢慢安静

关节阻尼产生与关节速度相反的阻力。在这个旋转关节上，线性阻尼力矩可以写成：

```text
τ_damping = −b · θ̇
```

速度越大，阻尼力矩的绝对值越大。它不断消耗机械能，让运动逐渐衰减。

打开实验，将阻尼先设为 0，再设为 0.12 和 0.8。保持初始角度相同，比较摆动和曲线包络的变化。无阻尼时，理想模型的机械能应近似保持；数值积分仍可能带来误差。

> 先改变一个参数，再观察它带来的差别。一次只问一个问题，通常更容易得到清晰的答案。

## 两种时间，各自负责什么

浏览器绘制画面的频率会变化，物理计算的时间步则应保持明确。本示例使用 0.002 秒的仿真时间步，正常速度下，每秒推进约 500 个物理步。

屏幕不需要为每个物理步绘制一帧。程序在一帧之间执行所需的物理计算，再显示当前状态。暂停和单步作用于物理时间，旋转视角只改变观察方式。

## 带回本地

从实验页下载 `pendulum.xml`、`run.py` 和运行说明。将文件放在同一目录，安装说明中的 MuJoCo 版本，然后运行：

```bash
python run.py pendulum.xml
```

本地与网页使用同一份 MJCF。比较结果时，也要保持初始状态、阻尼与时间步一致。
