Geometry transformation for the Feedstar journal display:
Each crystal-shell-{i}.glb retains only the Cube outer-shell mesh from the corresponding reference model.
Icon meshes, reference logo geometry, ConvexHull collision meshes and unrelated nodes were removed.
Only local-space geometry and all eight original shell vertex attributes are retained: POSITION, NORMAL, TANGENT, TEXCOORD_0, _peaks, _convexity, _thickness, _concavity.
The source contains no material or image resources. The extracted GLBs contain no materials, images, animation tracks or embedded reference-site code.
DRACO compression was decoded offline with the official glTF decoder bundled with the installed Three.js package. The output is ordinary glTF 2.0 GLB, with Float32 attributes and Uint16 triangle indices; no runtime Draco decoder is needed.
Source dimensions and orientation are unchanged; no simplification or new lossy quantization was applied after decoding.
